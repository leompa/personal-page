# Página Personal

Página personal en React + Vite para mostrar proyectos.

## Despliegue automático

El workflow en `.github/workflows/deploy.yml` despliega automáticamente a GitHub Pages en cada push a `main`.

### Pasos después de clonar:
1. `npm install`
2. Edita `src/projects.js` con tus proyectos.
3. Haz commit y push a `main`.
4. Ve a Settings > Pages y asegúrate de que la fuente sea GitHub Actions.

La URL será: https://leompa.github.io/personal-page/
